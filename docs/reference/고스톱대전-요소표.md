# 고스톱대전 요소표 — 스크린샷 10장에서 뽑은 전체 요소와 우리 게임의 상태

기준: 소유자가 준 스크린샷(대결 화면 4장, 국진 창, 삼광 연출, 여정 지도 2장, 챕터 컷, 타이틀·스플래시). "우리"는 v0.19 기준.
상태 표기: **있음** / **있음(다름)** / **없음→F단계** / **안 함(차별점이라 우리 방식)** / **물어볼 것**.

## 확인된 답(10-29)
- 빨간 게이지 = 상대 손패 장수(10칸). 미션 = 판마다 다른 지정 카드 2~3장을 모두 획득하면 점수 ×4, 유형 약 8개. 메타 요소 중 **미션만 가져온다**(냥·레벨·골드카드·대리치기는 안 함).

## 미션 설계 (F3에 구현, 규칙 엔진 밖)
- 판 시작(분배 직후)에 미션 1개를 뽑아 화투판 오른쪽 위 패널에 카드 그림과 배수를 표시. 미션 카드는 **내 손패에 없는 카드** 중에서 뽑는다(더미·상대 손패·바닥에 있음). 뽑기는 판마다 `seededRng`.
- 달성 판정: 내 획득패에 미션 카드가 전부 들어온 순간 패널이 금색으로 바뀌고 "미션!" 배너. 정산 시 최종 점수 × 배수(엔진의 `final`에 story 계층이 곱함. 결과창에 "미션 ×4" 줄 추가). 돈도 그 점수로 계산. 못 해도 벌칙 없음.
- 유형 8개(배수): ① 같은 월 2장(×2) ② 광 1장 + 지정 피 1장(×3) ③ 고도리 열끗 2장(×3) ④ 홍단·청단·초단 중 한 단 2장(×3) ⑤ 쌍피 2장(×3) ⑥ 지정 카드 3장(×4) ⑦ 비광 + 국진(×4) ⑧ 광 2장(×4). 1~3장은 초반(1~4장)엔 ①②④만 나오고, 5장부터 전부.
- 상대도 미션이 있나? → 없음(플레이어만). 기준작도 상대 미션 표시는 없었다.
- 미션 카드 획득을 노리는 플레이가 생기도록 AI는 모른다(공개 정보 아님). 테스트: 미션 카드가 손패에 없음, 달성 판정, 배수 적용, 초반 유형 제한.
