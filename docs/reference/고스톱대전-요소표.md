# 고스톱대전 요소표 — 스크린샷 10장에서 뽑은 전체 요소와 우리 게임의 상태

기준: 소유자가 준 스크린샷(대결 화면 4장, 국진 창, 삼광 연출, 여정 지도 2장, 챕터 컷, 타이틀·스플래시). "우리"는 v0.19 기준.
상태 표기: **있음** / **있음(다름)** / **없음→F단계** / **안 함(차별점이라 우리 방식)** / **물어볼 것**.

## 물어볼 것 (답을 받아야 넣을 수 있음)
① 상대 이름 옆 **빨간 8칸 게이지**는 뭐가 줄어드는 건가요? (상대 체력=돈이 떨어지면 파산? / 남은 판 수?)
② **MISSION**: 패널의 두 장을 이번 판에 획득하면 ×4인가요? 그 ×4가 점수인지 돈(냥)인지, 못 하면 벌칙이 있는지.
③ **"Q 바닥패보기"**를 누르면 정확히 뭐가 보이나요? (더미 다음 장? 상대 손패? 바닥에 깔릴 패?) 횟수 제한은?
④ **파란 세모**: "첫 출이면"이라고 하셨는데, 첫 턴에만 뜨는 건지, 매 턴 바닥과 맞는 패 전부에 뜨는 건지. 스크린샷에는 여러 장에 동시에 떠 있어 후자로 보입니다.
⑤ 메타 요소(냥 화폐·레벨·연승·골드카드·대리치기·미션) 중 **가져올 것**과 **우리 방식(집중력·기술·원화)으로 갈 것**을 정해 주세요. 제 추천: 연승·미션은 가져오고(재미), 냥·레벨·골드카드·대리치기는 안 가져옴(스토리 게임과 안 맞음).
