# Cursor 요청 06 — F2: 편의점·서린·아이템 + 2장·3장(마 사장)

v0.19를 모바일 비율 헤드리스로 돌려 프롤로그 → 지도 → 이발소 → 1장 대결 → 보상 → 집 해금까지 끊김 없이 이어지는 것을 확인했습니다(저장 데이터도 정확). 이번 요청은 F2와 작은 보정 3건입니다. 먼저 `docs/story/시나리오-바이블.md`의 2장·3장·3절(시스템)·7절(아이템)·8절(서린)을 다시 읽으세요.

## 0. 공통 제약
요청 05와 같다(규칙 계층·dialog.ts 수정 금지, 계획→연출→applyTurn 유지, 그림 요구 금지, 데이터는 src/story/). 상대별 말풍선은 dialog.ts를 고치지 말고 `src/story/lines.ts`에 DialogSet 데이터를 두고 기존 `DialogPolicy`에 넣어 쓴다.

## 1. 보정 3건 (먼저)
1. **그림 없는 컷**: 지금은 빈 어두운 상자 + 아래 작은 글자라 허전하다. 이미지 파일이 없으면 상자를 그리지 말고 글자를 **상자 자리 가운데에 크게**(22px, 줄 간격 1.5, 아이보리) 보여준다. 이미지가 있으면 지금 방식. 로더 404는 콘솔 오류로 남지 않게 `load.on('loaderror')`에서 조용히 넘기고, 못 읽은 경로는 개발 정보 모달에만 목록으로 보여준다.
2. **다음 목적지 표시**: 다음 장의 장소가 아직 잠겨 있으면(구현 전) ▶와 금색 테두리를 **집**에 두고 집 모달 첫 줄에 "다음 이야기는 아직 준비 중"을 적는다. 이번 요청이 끝나면 2·3장이 열리므로 실제로는 편의점/목욕탕이 가리켜진다.
3. 지도 헤더의 "집중력 100/100"과 장소 "집"처럼 글자가 겹쳐 검색되는 문제는 없지만, 노드 라벨 Text 객체에 `setName('place:<id>')`를 붙여 두라(테스트·자동화용, 화면 변화 없음).

## 2. 돈과 일반 대결
1. `Progress.money`를 대결에 연결한다. 일반 대결(장소 모달의 "판 치기")은 장소별 1점당 판돈(places.ts에 `stakePerPoint`: bath 10000, market 20000, harbor 50000, hotel 200000, barber·home 0). 결과 `final` 점수 × 판돈을 승자가 가져간다. 돈은 0 아래로 내려가지 않는다(부족하면 가진 만큼만). 장 대결(상대가 인물)은 판돈 0.
2. 입장 조건: 소지금이 판돈 × 7 미만이면 "판에 앉을 돈이 없다" 안내 + 집·편의점 안내. 막히는 상황은 서린 '야간 근무 식사' 사건(아래)으로 늘 풀 수 있다.
3. 지도 헤더 소지금이 바뀔 때 "+N원/−N원"이 떠오른다(fx.scorePulse 재사용).

## 3. 편의점 (2장)
1. 장소 모달(store): [서린과 대화] [상점] [밤차와 한 판(연습, 판돈 0)] [닫기]. 처음 방문 시 2장 before 장면(바이블 2장 대사 전부) 자동 재생 → `ch2` 완료 처리는 **밤차 대결 승리** 시(보상 기술 없음, 캔커피·사탕 해금, 목욕탕 해금, 2장 after 장면 "마 사장? 목욕탕 뒤에서 하는 사람").
2. 상점: items.ts의 `unlock` 조건을 `Progress.flags`로 판정. 처음엔 삼각김밥만, 2장 대화 뒤 캔커피, '재고 정리' 사건 뒤 사탕, 4장 도시락, '첫 귀가' 뒤 안대(장비, 동작은 F3). 가격(원): 김밥 1500, 커피 2500, 사탕 1200, 도시락 6000, 안대 15000. 가방 `Progress.bag: Record<ItemId, number>`.
3. 아이템 동작(이번에 3개): 삼각김밥 = 지도에서 사용, 집중력 +20 / 캔커피 = 지도에서 사용, 집중력 전부 + 다음 대결 첫 기술 비용 −10(플래그) / 포도당 사탕 = 대결 중 기술 줄 옆 "가방" 버튼으로 사용, +25, 대결당 1회. 나머지는 데이터만.
4. **서린 관계·이벤트** (`src/story/serin.ts`):
   - `Progress.serin: { affinity: number; visits: number; lastEventDay: number; pity: number; seen: string[] }`. affinity는 방문(+1, 하루 1회)·대화 선택(+1~2)·약속 이행(+3)으로만 오른다. 돈은 올리지 않는다.
   - 방문마다 하루 1회 사건 추첨: 바이블 8절 표에서 이번에 **3개 구현** — 야간 근무 식사(음식·집중력·돈 +20,000 "손님이 두고 간 거야"), 교재비 부족(돈 −50,000 선택, 거절 가능, 이후 답례 플래그), 재고 정리 부탁(사탕 해금). 나머지 5개는 데이터만(제목·대사).
   - 답례 등급 추첨: 일상 55 / 유용 28 / 희귀 12 / 매우 희귀 4 / 특별 1 (%). 희귀 이상 10회 미발생 시 다음은 희귀 이상 확정(pity). 희귀 이상은 이번엔 "고물상 삼촌을 소개받았다(투시경 해금 예정)" 플래그만 세운다. 난수는 `seededRng(day × 1000 + visits)`로 재현 가능하게.
   - 대화 화면은 story 씬 재사용(line 장면). 서린 초상화는 `assets/characters/serin-neutral.png`(없으면 이니셜).
5. 테스트: 상점 해금 조건, 가방 증감, 아이템 효과(집중력 상한), 등급 확률 합 100·pity, affinity가 돈으로 오르지 않음, 2장 완료 조건.

## 4. 목욕탕 뒤와 마 사장 (3장)
1. 장소 모달(bath): [판 치기(일반, 판돈 1점 1만)] [마 사장과 대결(3장)] [닫기]. 일반 상대 `stranger` 프로필(strategic, 약한 가중치 — AI_WEIGHTS를 바꾸지 말고 `beginner`와 `strategic`을 턴마다 50:50으로 섞는 래퍼 정책으로 "쉬운 상대"를 만든다. ai.ts 수정 없이 `src/story/policies.ts`에서 두 Opponent를 감싼다).
2. 마 사장 대결 입장 조건: 목욕탕 일반 대결 2승(플래그). 3장 before 장면 → 대결 → after(장부·"남의 빚을 사들였다"·서린 어머니 이름) → 보상 태연한 얼굴 + 마스크 해금(데이터) + 시장 해금 + `ch3` 완료.
3. **도발형 동작**(`OpponentProfile.taunt`): 내 기본 점수가 7 이상이 되어 고/스톱 창이 뜨기 직전, 마 사장 말풍선(lines.ts: "한기석 아들이 이렇게 겁이 많았나?", "여기서 접으면 네 아버지랑 똑같지." 등 4개)을 띄우고 고/스톱 창에 작은 "(도발)" 표시. 내가 고를 외치면 그 판 남은 동안 상대의 고/스톱 정책을 공격적으로(래퍼: `decideGoStop`이 상대 기본 점수 ≥ 7이면 1고까지 → 2고까지 허용). 내가 스톱하면 변화 없음. 즉 "도발에 반응하면 상대도 세진다"를 구현한다. 규칙 함수(canDecide/canGo)는 그대로.
4. **태연한 얼굴**(기술 동작 1단계): 대결 중 버튼, 비용 25, 판당 1회. 사용하면 이번 판 남은 도발이 뜨지 않고 "(도발)" 표시도 없다. 의심도 −30 부분은 F3에서.
5. 눈썰미 강화는 아직 없음. 기술 버튼 줄은 배운 기술 수만큼 가로로(최대 4개, 폭 140).
6. 테스트: 도발 조건(7점 직전·판당 1회), 고 후 정책 전환, 태연한 얼굴로 도발 차단, 래퍼 정책이 공개 정보만 보는 것(기존 ai.test의 "같은 공개 정보 → 같은 판단" 방식), 3장 입장 조건·완료 처리.
