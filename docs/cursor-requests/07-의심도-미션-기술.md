# Cursor 요청 07 — F3-시스템: 의심도 · 미션 · 기술 4종 · 장비 · 기준작 연출 보정

v0.20을 모바일 비율 헤드리스로 돌려 1장 → 편의점(2장 장면·서린 사건·상점·밤차) → 목욕탕 일반 2승(돈 12만→32만) → 마 사장 도발 말풍선·"(도발)" 표시 → 태연한 얼굴 보상 → 시장 해금까지 끊김 없이 확인했습니다. 오류 없음.
이번 요청은 4~6장을 올릴 **판 위의 시스템**입니다. 장 내용(복희·태오·봉구·큰 판)은 다음 요청 08. 먼저 `docs/story/시나리오-바이블.md` 3절(시스템)·7절(아이템)과 `docs/reference/고스톱대전-요소표.md`의 '미션 설계'·4절(내 영역)을 읽으세요.

## 0. 공통 제약
요청 05·06과 같다. 규칙 계층(game/score/cards/ai/beginner/scenarios/dialog) 수정 금지. 단 **예외 하나**: 들통·접기 같은 "합의 종료"는 규칙 변경이 아니라 종료 사유 추가이므로 `GameState`에 `forfeit(loser)` 한 가지 동작만 추가해도 된다(아래 1-4). 기술·미션·의심도는 화면 계층(`src/story/`, TableScene)에서 상태를 읽거나 정해진 동작을 요청하는 범위 안에서 구현한다. 그림 요구 금지(종·아이콘은 도형).

## 1. 의심도 (`src/story/suspicion.ts`, 순수 함수 + TableScene 표시)
1. 대결마다 0에서 시작, 0~100. 속임수 기술·장비를 쓰면 오른다. 상대 프로필에 `sharpness: 0.5~2.0`(눈썰미 배율)을 추가해 상승폭 = 기본값 × sharpness. 초기값: 마 사장 0.6, 밤차·stranger 0.8, 복희 1.0, 봉구 1.0, 큰 판 1.5, 뱀눈 1.2, 태오 1.3, 문지기들 1.5, 백무진 2.0, 대식·아버지 0(연습·이야기 판에서는 오르지 않음).
2. 표시: 내 정보 패널 집중력 바 옆에 **붉은 눈 모양 바**(가로 120). 속임수 기술을 하나도 안 배웠으면 바 자체를 그리지 않는다(5장 바꿔치기 전까지 안 보임 — 바이블 5장 "처음 쓰는 순간 게이지가 처음 보인다").
3. 상승 순간 연출: 바가 흔들리고(80ms) 상대 초상화가 '!' 배지로 반응(기존 portraitReact 'surprise' 재사용), 70 이상이면 상대 말풍선 "손이 빠르네." 같은 경고 1회(lines.ts에 상대별 2줄).
4. **들통(100 도달)**: 즉시 그 판 패배. `GameState.forfeit(loser: 0|1)`를 추가해 `result = { outcome:'승리', winner: 1-loser, base: 상대 기본 점수, goCount: 상대 고 횟수, settled: settlementPoints(...), baks: [], multiplier: 1, declared: [], declMultiplier: 1, final: settled, forfeit: true }`로 확정(RoundResult에 `forfeit?: boolean` 추가, 기존 테스트 영향 없음). 화면: 붉은 막 + 먹물 배너 "들통!" 600ms → 결과창 제목 "들통". 돈은 그 점수로 정산. 추가로 해당 장소 `Progress.flags['banned:<place>:<day>']`로 **하루 출입 금지**(지도에서 노드가 붉은 테두리, 모달에 "오늘은 못 들어간다"). 장 대결(인물)에서 들통나면 출입 금지 없이 "한 판 더"만.
5. 내리기: 태연한 얼굴 사용 시 −30(06의 도발 차단과 함께 동작), 무표정 마스크 장비 1회 −30, 판이 끝나면 0.
6. 테스트: 상승 공식·sharpness, 100 도달 시 forfeit 결과 형태, 태연한 얼굴 −30, 정직 기술은 0, 출입 금지 플래그가 다음 날 풀림.

## 2. 미션 (`src/story/mission.ts`)
요소표 '미션 설계' 그대로. 
1. 판 시작(분배 직후, 'hand' 진입 전)에 미션 1개 추첨: `seededRng(roundSeed)`. 미션 카드는 **내 손패에 없는 카드** 중에서. 유형 8개와 배수: ① 같은 월 2장 ×2 ② 광 1 + 지정 피 1 ×3 ③ 고도리 열끗 2 ×3 ④ 한 단(홍·청·초) 2 ×3 ⑤ 쌍피 2 ×3 ⑥ 지정 3장 ×4 ⑦ 비광+국진 ×4 ⑧ 광 2 ×4. 1~4장은 ①②④만, 5장부터 전부. 연습 대결·이야기 판(대식·아버지)에는 미션 없음. 일반 대결과 장 상대 대결에는 있음.
2. 화면: 화투판 오른쪽 위 작은 패널(폭 150) "MISSION" 글자 + 미니 카드 2~3장 + "×N". 내 획득패에 들어온 카드는 패널에서 금색 테두리. 전부 획득하면 패널이 금색으로 바뀌고 "미션!" 금색 배너(FX.bannerCombo).
3. 정산: 결과에 story 계층이 곱한다 — 결과창 "최종" 줄 위에 "미션 ×N" 줄, 최종 점수와 돈 모두 × N. `declareStop`/`forfeit`의 result는 손대지 않고 TableScene이 `missionMultiplier`를 따로 들고 표시·정산에 곱한다. 나가리면 미션 무효.
4. 테스트: 손패에 없는 카드만, 유형별 달성 판정, 장별 유형 제한, 배수 적용, 나가리 무효.

## 3. 기술 4종 동작 (`useSkill` 확장, skills.ts 수치 그대로)
| 기술 | 동작 | 비용/횟수 | 의심도 |
|---|---|---|---|
| 눈썰미 강화 | 4장 이후(`Progress.flags['eye+']`) 더미 윗장 **2장** 보기, 판당 2회 | 20 / 2 | 0 |
| 태연한 얼굴 | 06 동작 + 의심도 −30 | 25 / 1 | 0 |
| 시선 돌리기 | 이번 턴 상대 말풍선 역정보 무시(08의 복희용 플래그 `ignoreBluffThisTurn`) + 상대 손패의 **월 분포 힌트** 1회: "상대 손패에 1·4·9월이 있다" 같은 문장(장수 아닌 월 집합 중 무작위 3개, 공개 정보 아님이지만 기술이므로 허용) | 20 / 1 | 0 |
| 바꿔치기 | 내 손패 1장을 골라 더미 윗장과 교환. 성공률 70%(행운의 동전 +15%p, 최대 90%). 실패하면 교환 없이 의심도 +40. 성공 시 의심도 +25. **GameState에 `swapHandWithDeck(player, cardId)`** 추가(순수한 배열 교환, version+1, 48장 보존). 선택 UI: 기술 버튼 → 손패 위에 "바꿀 패를 고르세요" 캡슐, 손패를 누르면 교환 → 더미 윗장 뒤집기 연출(flipTo) 뒤 손패에 들어옴 | 35 / 1 | +25 |
- 기술 버튼 줄은 배운 순서대로 최대 4개. 5개째(간파·접기)는 08에서 두 줄로.
- 테스트: swapHandWithDeck 48장 보존·version 증가·상대 턴엔 거부, 성공률 경계(동전), 실패 시 의심도.

## 4. 장비 2칸 (`Progress.gear: ItemId[]`, 집 모달 [기술·장비])
1. 집 모달에 [기술·장비] 추가: 배운 기술 목록(설명·비용) + 장비 2칸(가방의 gear 아이템을 장착/해제). 대결 중에는 바꿀 수 없다.
2. 동작 4개: 숙면 안대(집 휴식 뒤 첫 대결 집중력 +30, 플래그) / 무표정 마스크(대결 중 버튼, 의심도 −30, 1회) / 투시경 안경(대결 중 버튼, 상대 손패 무작위 1장을 3초 공개, 1회, 의심도 +20) / 행운의 동전(소모품, 다음 바꿔치기 성공률 +15%p). 진동 손목시계·회중시계는 데이터만(08·F4).
3. 투시경·마스크 버튼은 기술 줄 오른쪽에 작은 장비 버튼으로(아이콘 없이 글자).
4. 상점 해금: 안대(첫 귀가 사건 → 이번엔 "집에서 처음 휴식하면" 플래그로 대체), 마스크(3장 완료, 이미 있음), 투시경(서린 희귀 답례 "고물상 삼촌" 플래그 → 상점 뒷방), 동전(5장 태오 → 08. 이번엔 상점에 임시로 노출하지 않음).
5. 테스트: 장착 2칸 제한, 안대 보너스 1회 소모, 마스크 −30, 투시경 공개 대상이 상대 손패에 있음.

## 5. 기준작 연출 보정 (요소표 4절)
1. **흔들기**: 흔들기 가능한 월의 카드에 금색 테두리 + 카드 오른쪽 위 작은 **종 모양**(도형: 사다리꼴 + 작은 원, 금색). 누르면 종이 좌우로 흔들리는 트윈 300ms + 합성 종소리(sound.ts에 'bell': 2kHz 사인 + 짧은 감쇠, 멜로디 없음) 뒤 기존 세 장 공개 연출. 폭탄 카드는 지금 주황 배지 유지.
2. **기회 패**: 붉은 기회 패를 여러 장 늘어놓지 않고 **한 장에 숫자 배지**(남은 횟수)로. 누르면 지금처럼 더미만 뒤집기.
3. 고·흔들기·폭탄 칩을 **아이콘 자리 3개**(원형, 32px)로: 고=붉은 원에 "고N", 흔=금색 원에 "흔N", 폭=주황 원에 "폭N". 0이면 회색. 그림은 나중에 교체(이미지 발주 C).
4. 상대 패널에 **상대 소지금**(원화, 상대 프로필 `money`, 장 상대는 바이블 분위기대로 임의 값: 마 사장 850만, 복희 300만, 봉구 4,000만 등; 일반 상대는 내 소지금의 1.5배) 표시. 승패로 변동은 표시만(저장 안 함).
5. 국진 창 버튼 색: 열끗 = 노랑, 쌍피 = 주황(기준작 예/아니요 색).
6. 지도 맨 위에 **현재 장 대표 컷**(chapters.ts `cover` 경로, 없으면 어두운 패널에 장 제목만) 폭 640×240. 그림은 발주 목록에 추가(`assets/story/cover-chN.png`).
