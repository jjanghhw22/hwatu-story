v0.23을 모바일(360×780) 헤드리스로 확인했습니다. 봉구 큰 숫자 타이머("3" 빨강), 7장 장면 흐름(수상한 방문객 → 서류 → 박 기사, 서린 상반신), 뱀눈 속임수 잡기 창("속임수다! … 지금 잡을까?") → 금색 막 "잡았다!" → 결과 "최종 7점", 태오 "그거 또 쓸 줄 알았어." + 눈썰미 "읽혔다", 아버지 손패 읽기("1월은 아껴 둬 봐야 소용없다."), "불리할 땐 접는 거다." 모두 동작합니다.
정하신 부분(8장 선택을 결과창 버튼으로, 접기는 기술 줄 버튼으로, 회중시계 대상, 보탠 대사)은 승인합니다. 접기를 고/스톱 창에 넣지 않은 판단이 맞습니다(고/스톱 창은 내가 이기고 있을 때만 뜨므로) — 바이블은 제가 고쳐 두었습니다.
먼저 `docs/story/시나리오-바이블.md` 10·11장·에필로그와 8절 관계 분기를 읽으세요. 공통 제약은 09와 같습니다(규칙 계층 수정 금지, forfeit 외 예외 없음).

## A. 보정 2건 (먼저 — 9장이 실제로 막힐 수 있음)

### A-1. 기술 버튼이 5개를 넘으면 사라진다 (버그)
현상: 9장 시점 기술이 눈썰미·태연·시선·바꿔·간파 5개 + 가방이라 줄이 꽉 찬다. 아버지 판에서 임시 접기가 생겨도 6번째라 **화면에 그려지지 않아** 누를 수 없다. 태오 버튼까지 생기면 더 밀린다.
기대: 기술 버튼이 5개(가방 제외)를 넘으면 **두 줄**로. 한 줄 최대 4개 + 가방은 아랫줄 맨 끝 고정. 늘어난 52px는 긴 화면 여분 → 내 획득패 패널 순으로 가져온다(1280에서 화투판 최소 440 유지). 순서: 배운 순서, 단 **임시 접기와 태오 버튼은 윗줄 맨 앞**(눈에 띄게). layout.test.ts에 "기술 8개 + 가방이 모두 화면 안, 서로 겹치지 않음" 추가.

### A-2. 접기를 가르치는 순간 아버지가 이미 고를 불렀다
현상: 아버지는 7점에서 바로 고를 부르므로, "아버지 ≥ 5 · 내가 낮음" 조건이 처음 맞는 때가 대개 아버지가 이미 1고 8점인 순간이다. 접기는 "상대가 고 중이면 불가"라서 가르쳐 놓고 못 쓴다.
기대: 가르침 조건을 **아버지 기본 5~6점이고 아버지 고 0회, 내 점수가 더 낮을 때**로. 가르친 뒤 그 판에서 아버지는 **다음 1턴 동안 고를 부르지 않는다**(플레이어가 접을 시간). 이 판에서 조건이 한 번도 안 오면, 판이 끝난 뒤 after 장면 앞에 아버지 대사 "불리할 땐 접는 거다." 한 줄로 가르치고 접기를 정식 습득시킨다(9장 진행이 막히지 않게). 테스트로 세 경로 확인.

## B. 10장 — 왕의 식탁 (백운호텔 초대전)
1. 10장 시작(9장 다음 날 호텔 방문): before 장면 = 바이블 10장 사이 장면 중 **대식의 담보 제안**("이번에는 아무도 집 걸지 마요."). 호텔 모달: [초대전 1 — 민정호] [초대전 2 — 차유라] [초대전 3 — 구상만] 순서대로 열림. 판 사이에 지도로 나가 쉬거나 편의점에 갈 수 있다(진행 저장).
2. **서린의 마지막 상품**(10장 중 편의점 첫 방문, 1회): 바이블 대사("환불은 안 돼." / "아직 얼마인지도 안 물어봤는데?" / "그러니까 살아서 가져와. 고장은 봐줄게."). 새 장비 **서린의 부적**(`serinCharm`): 판당 1회, 의심도가 100에 닿는 순간 70으로 되돌린다(들통 1회 막기). 가격 없음.
3. **관계 분기**(10장 중 편의점 두 번째 방문, 1회, affinity ≥ 8일 때): "너 내가 왜 도와주는지 알았잖아." / "알았어. 그래서 고맙기도 했고, 무섭기도 했어." → 선택 3개 [친구로 남자] [천천히 가 보자] [잠깐 거리를 두자] → `serin.route = 'friend' | 'slow' | 'distance'`. 어느 쪽이든 핵심 보상은 같고 대사만 다르다. affinity < 8이면 이 사건 없이 route = 'friend'.
4. 문지기 셋(각각 판돈 0, 장 대결, 미션 있음, sharpness 1.5):
   - **민정호 '보수형'**: 고/스톱 가능하면 항상 스톱. 평가 가중치는 STRATEGIC에서 상대 조합 저지 ×1.3, 피박·광박 완화 ×2(learner.ts의 래퍼 방식 재사용, 공개 정보만). 승리 대사·결과 대사 2줄.
   - **차유라 '배우'**: bluff 0.8(복희 구조 재사용, 대사 새로 3+3+3). 추가로 그녀 차례 25% 확률로 **가짜 흔들기 예고** — 말풍선 "흔들어 볼까?"와 종소리만, 실제 선언 없음. 시선 돌리기를 쓴 판이면 그 말풍선에도 "(거짓)" 표시.
   - **구상만 '봉쇄형'**: 판당 **봉쇄 3회**. 내가 기술을 쓰면(가방 제외) 처음 3번은 막힌다 — 집중력은 소모되고 효과는 없음, 화면에 "구상만이 막았다 (남은 봉쇄 N)" + 막힌 기술 버튼에 X 300ms. 상대 패널에 방패 칩 "봉쇄 3". 봉쇄가 0이 된 뒤부터 정상. (공략: 싼 기술로 봉쇄를 먼저 소모)
5. 셋 다 이기면 **백무진 등장** 장면(바이블 10장 끝 대사 전부) → **선택** [자리를 받아들인다] → 엔딩 C / [마지막 판을 요구한다] → `ch10` 완료, 11장.
6. 테스트: 문지기 순서 잠금, 정호 항상 스톱, 유라 가짜 흔들기가 상태(version·shakes)를 바꾸지 않음, 상만 봉쇄 3회 후 정상·집중력 소모, 부적이 판당 1회 100→70, 관계 분기 조건과 기본값.

## C. 11장 — 왕이 없는 밤 (백무진)
1. 기술 사용 기록: 지금부터 `Progress.counters['skill.<id>']`를 기술 사용 때마다 +1(전 장 공통). 11장 1단계에서 사용 횟수 상위 2개를 봉쇄(기록이 없으면 눈썰미·바꿔치기).
2. 무진 대결은 **한 판 안에서 3단계**(`src/story/king.ts`, 프로필을 판 중간에 교체, sharpness 2.0):
   - **1단계 견제**(시작~): 상위 2개 기술 버튼 잠김("왕이 봤다"). STRATEGIC.
   - **2단계 흔들기**(더미 ≤ 14장 또는 내 기본 ≥ 5가 처음 되는 순간): 무진 말풍선 + **판돈 제안 창** "판을 두 배로 키우지." [받는다] / [거절한다]. 받으면 이 판 최종 점수 ×2(미션처럼 story 계층에서 곱함), 무진 고 정책 공격적(provoked, 최대 2고). 거절하면 무진이 "역시 아버지 아들이군." 도발 1회(태연한 얼굴로 막을 수 있음). 봉쇄 해제.
   - **3단계 왕의 손**(더미 ≤ 6장 또는 무진 기본 ≥ 5): cheat `{ perTurn: 0.6, maxPerMatch: 2 }` 활성. 문지기 셋의 "준비 동작"과 같은 단서로 시작 순간 무진 초상화 '!' + "손끝이 멈췄다" 메시지 1회. 간파로 잡으면 들통 → 내 승리.
   - 단계가 바뀔 때마다 **컷인 1장**(대화창만, 0.8초 자동 진행): 2단계 "서린이 배송 기사에게 봉투를 건넨다.", 3단계 태오 수락이면 "태오가 직원 통로 문을 연다." / 아니면 "시장 트럭이 호텔 뒷문에 선다."
3. 승리 → after 장면 "한 번 더." "이번엔 네가 원하는 거 전부." → **최종 고/스톱 창**(기존 고/스톱 모달 디자인, 제목 "마지막 선택"): 
   - [스톱] → 엔딩 A.
   - [고] → **추가 승부**: 무진 4단계(cheat perTurn 0.6·max 3, 정직 기술 모두 봉쇄, 미션 없음). 이기면 엔딩 B, 지면 "한 판 더"(추가 승부만 반복). 
   패배 시 11장 본 판은 "한 판 더".
4. 테스트: 단계 전환 조건, 1단계 봉쇄 대상(사용 기록 상위 2), 판돈 ×2 정산, 3단계 cheat 활성, 최종 선택 분기, 추가 승부 반복.

## D. 엔딩 3종 · 에필로그 · 이후
1. `src/story/endings.ts`에 엔딩 데이터.
   - **A(스톱·기본)**: "다음 사람 기다리세요." / "왕이 되러 온 거 아니었나?" / "아버지 데리러 왔습니다." → 에필로그 전체.
   - **B(고·왕좌)**: 왕좌 컷 → "새 얼굴들이 도윤의 자리를 둘러싼다." → 짧은 에필로그(이발소 장면 없음, 마지막 문장 "이번에도 집에 돌아오지 못했다.").
   - **C(10장 수락)**: 쉬운 왕좌 → "이발소 문이 닫혀 있다." 에필로그 없음.
2. **에필로그**(A만, 바이블 그대로): 아버지 조사 협조 → 대식 이발소 → 복희 반찬값 → 태오(수락: 시장 배송 / 거절: 항구를 떠남) → 서린 복학 신청서 → 편의점 봉투:
   - route 'slow' 그리고 affinity ≥ 12 → "토요일 비워 놔." / "이번엔 누구 삼촌인데?" / "이번엔 삼촌 없어." → **영화표 두 장**.
   - 그 밖 → 손편지(friend) / 작별 선물(distance). 어느 쪽도 실패처럼 보이지 않게 같은 길이·같은 음악 없음 연출.
   - 마지막: 이발소 "이번엔 어떻게 잘라?" "양쪽 똑같이요." → 검은 화면 "이번에는 집에 돌아왔다."
3. **크레딧**(간단 스크롤: 제목·제작·화투 도안 출처·글꼴·엔진) → 지도로 복귀. `Progress.flags['ending.A|B|C']` 저장, 지도 헤더에 "엔딩 A 달성" 작은 배지. 엔딩 뒤에는 모든 장소의 일반 대결을 계속 할 수 있다(이야기 버튼은 "다시 보기"로).
4. 메뉴 > 개발 정보에 **장 바로가기**(개발용): 각 장 시작 상태로 진행을 덮어쓰는 버튼(확인 창 후). 테스트·시연용.
5. 테스트: 엔딩 플래그, 에필로그 분기(route·affinity), 엔딩 C는 에필로그 없음, 엔딩 뒤 일반 대결 가능.
