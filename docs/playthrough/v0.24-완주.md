# v0.24 완주 테스트 보고 (10-29)

## 방법
배포와 같은 빌드를 헤드리스 Chromium의 휴대폰 화면(360×780, 터치)으로 띄우고, 사람이 누르듯 **화면에 보이는 버튼과 지도의 ▶ 노드만** 누르는 스크립트로 진행했다. 대결은 단순한 규칙(바닥과 맞는 패 중 점수 높은 패, 고/스톱은 항상 스톱, 국진은 쌍피, 속임수 상대에겐 간파를 켜고 잡기)으로 쳤다. 저장소를 비운 새 게임에서 시작. 연출 줄이기 켬.

## 발견 (→ 요청 11)
1. **돈 막힘**: 4장 끝 소지금이 운에 따라 27만~51만. 항구 입장 35만에 못 미치면 5장 진행 불가.
2. **10장 서린 이벤트 누락**: 호텔로 바로 가면 부적·관계 선택이 안 나오고 에필로그가 무조건 손편지.
3. **하루가 안 흐름**: 완주 내내 DAY 2. 집·휴식이 필요 없고 서린 호감이 쌓이지 않아 영화표 조건(12)에 닿기 어렵다.
4. 크레딧 문구 정리.
