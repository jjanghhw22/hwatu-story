# 이미지 발주 목록 (ChatGPT 등 외부 제작용)

코드는 **파일이 있으면 그림, 없으면 글자**로 동작하므로, 아래 파일명·경로 그대로 넣기만 하면 바로 화면에 뜬다. 순서는 지금 필요한 것부터.
공통 스타일 기준: 이미 승인된 두 장(`public/assets/characters/barber-neutral.png`, `hero-neutral.png`)과 같은 **2D 만화풍, 깔끔한 선, 차분한 채도**. 실사풍·3D·과한 광택 금지. 글자(한글 간판 등)는 그림 안에 넣지 말 것(그림 속 글자는 AI가 틀리게 그리고, 글자는 코드가 얹는다).

## 요청 방법 팁
- 한 번에 한 인물씩, "같은 세계관의 기존 캐릭터 두 장(첨부)과 같은 화풍으로"라고 두 장을 첨부해서 요청하면 톤이 맞는다.
- 투명 배경이 안 나오면 흰 배경으로 받아 나중에 지우면 된다(코드는 투명을 기대하지만 흰 배경도 원형으로 잘려서 큰 문제는 없다).
- 파일을 받으면 위 경로에 **파일명 그대로** 넣고 Cursor에 "새 그림 파일을 preload 목록과 대조해 누락·크기 확인만 보고해 줘"라고 하면 된다.
