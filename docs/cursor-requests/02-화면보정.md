# Cursor 요청 02 — 실제 화면 확인 결과 보정

v0.16 빌드를 헤드리스 Chromium(720×1280)에서 한 판 끝까지 돌리고 분배 연출·시나리오 화면을 찍어 확인했습니다. 규칙 오류·예외는 없었고 아래는 모두 화면 배치 문제입니다. 요청 01의 "0. 공통 제약"을 그대로 적용합니다(규칙 계층 수정 금지, 계획→연출→applyTurn 구조 유지, 수치는 layout.ts·FX 상수로).

각 항목은 "현상 → 기대"입니다. 번호 순서대로 처리하고, 항목마다 바꾼 파일과 상수를 보고하세요.

## 1. 안내 줄과 손패 윗줄 화살표가 겹친다 (우선)
현상: 손패가 7장 이상일 때 윗줄 카드의 파란 화살표가 그 위의 안내 글자("손패를 누르면 내기 · 폭탄/흔들기 …", REGIONS.skill)와 정확히 겹친다.
기대: 안내 줄(SKILL_H 24)을 없앤다. 문구는 이미 메뉴 > 규칙 안내에 있으므로 화면 상시 표시가 필요 없다. 비운 24px는 손패 영역(REGIONS.hand)에 더해 윗줄 위쪽 여백으로 쓴다(화살표 높이 18 + 왕복 6 + 여유). layout.test.ts의 영역 테스트에서 skill 항목을 제거한다.

## 2. 점수 변화 "+N"이 점수 배지 숫자 위에 겹친다
현상: pulseScores가 "+1"을 배지 안 숫자 바로 왼쪽에 띄워 "+1 1점"처럼 읽힌다(main.ts 412행 부근, scorePulse 호출 좌표).
기대: "+N/−N"은 점수 배지 **왼쪽 바깥**(배지 x − 10, 오른쪽 정렬, 세로는 배지 가운데)에서 시작해 위로 떠오른다. 배지 안쪽으로는 들어오지 않는다. scorePulse의 origin을 (1, 0.5)로 받을 수 있게 매개변수를 추가하거나 호출 좌표만 조정한다. 배지 숫자 자체의 1.15배 확대 효과는 유지.

## 3. 상대 말풍선이 점수 배지를 가린다
현상: 말풍선("오, 제법인데?")이 speechZone의 오른쪽 끝에 정렬되는데, 그 끝이 새 점수 배지(x 594~690)와 겹친다.
기대: speechZone의 오른쪽 경계를 점수 배지 왼쪽 − 12로 잡는다(layout.ts의 INFO 상수로 계산, 숫자를 직접 쓰지 않음). 말풍선이 길어 폭이 모자라면 글자를 줄이지 말고 zone 폭에 맞춰 word wrap 두 줄까지 허용(높이 34 → 최대 52, 패널 안에 머무름). 기존 "말풍선 자리가 점수와 겹치지 않는다" 테스트를 배지 기준으로 갱신한다.

## 4. 분배 중 더미 장수 배지가 처음부터 "20"이다
현상: 분배 연출 내내 더미 옆 배지가 20으로 고정돼 있다(이미 분배가 끝난 상태값).
기대: 'dealing' 단계에서는 표시 장수를 `state.deck.length + (아직 도착하지 않은 분배 카드 수)`로 계산해 48에서 20까지 줄어들게 한다. 상태(GameState)는 건드리지 않고 TableScene이 남은 카드 수를 세어 drawTable의 deckCount에 넘긴다.

## 5. 선택 단계에서 펼친 두 장이 이웃 월 카드를 덮는다
현상: 같은 월 두 장을 펼치면 두 번째 장이 옆 자리의 다른 월 카드 위로 올라간다(이웃이 어둡게 되고 펼친 장이 맨 위라 조작은 가능).
기대: 펼침 방향을 "빈 쪽"으로 고른다 — 자리의 오른쪽 이웃 자리 중심과의 거리가 왼쪽보다 가까우면 왼쪽으로 펼친다(지금은 열 위치로만 판단). 그래도 이웃과 겹치면 가로 대신 위쪽으로 펼친다(두 번째 장을 y − (h × 0.55)). 펼친 장은 회전 0 유지. layout.test.ts "선택 단계 펼침" 테스트에 "펼친 두 장이 다른 월 카드와 겹치지 않는다"를 추가하되, 12자리 모두 찬 극단 상황은 제외하고 8장 이하에서 보장한다.

## 6. 빈 획득 패 패널이 너무 무겁다
현상: 판 시작 직후 양쪽 획득 패 패널이 84px 높이의 진한 상자로 비어 있어 화면이 무거워 보인다.
기대: 획득 패가 0장일 때는 패널 배경 알파를 0.35로 낮춘다(테두리는 유지). 카드가 하나라도 들어오면 기존 알파. panel() 호출에 알파 인자를 추가하는 방식으로.

## 7. 손패를 내고 더미 위에 들고 있는 카드가 더미 배지를 가린다 (낮음)
현상: holdRect의 카드가 더미 오른쪽 아래 장수 배지를 덮는다.
기대: holdRect를 더미 위쪽(y − h × 0.35)으로 올리거나, 들고 있는 동안 배지를 그리지 않는다. 둘 중 간단한 쪽.

## 8. 확인됐고 그대로 둘 것 (바꾸지 말 것)
- 분배 순서·속도(약 1.6초), 손패 6+4 배치, 바닥 12자리 흩뿌림과 기울기, 획득 패 4묶음과 배지, "광박" 빨간 글씨(고/스톱 시나리오에서 표시 확인), 선 배지, 칩, 메시지 캡슐, 결과창, 기회 패 표시 — 모두 의도대로 보였다.
- 폭탄·흔들기 배지와 화살표 동시 표시도 정상.
